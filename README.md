# 漢字テスト・ふくしゅうプリント

小学1〜6年の漢字（学年別漢字配当表の1026字）で、次のプリントをA4のPDFでつくれる無料のWebアプリです。

- **漢字テスト**：学年・学期から出題、または自分で入力したことばで出題（こたえのページつき）
- **練習プリント**：お手本・なぞり・練習マス・ことば欄
- **かくにん表**：書けたらチェック
- **お手本（漢字帳）**：A4たての漢字帳のマスに、ことばとよみを入れたお手本

## 使い方

ブラウザで次のページを開くだけです。インストールや登録はいりません。

👉 https://uramotokou-hash.github.io/kanji-print/

1. 学年をえらぶ
2. 出題する範囲（学期・前期後期・1年間）をえらぶ
3. つくるものをえらび、「PDFをつくる」を押す

学期ごとの漢字は、お使いの教科書を見ながら各自で設定します（設定はその端末のブラウザにだけ保存され、ほかの人には共有されません）。
